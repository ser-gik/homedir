## My vim setup

This repo contains my configuration for Vim/Neovim. To use on a new machine:
```sh
git clone --bare https://github.com/ser-gik/homedir.git ~/.homedirgit
echo "alias homedirgit='git --git-dir=$HOME/.homedirgit/ --work-tree=$HOME'" >> ~/.bashrc
homedirgit config status.showUntrackedFiles no
homedirgit checkout
```
